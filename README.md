# 👁️ O Olho do Prime Void

**O Olho do Prime Void** é uma ferramenta para consulta e análise de Gamepasses do Roblox.

A aplicação permite pesquisar Game Passes por ID ou link e visualizar informações públicas relevantes de forma rápida e organizada.

## ✨ Recursos

- Pesquisa por ID ou link de Game Pass
- Suporte a múltiplas pesquisas
- Nome, criador e preço da Game Pass
- Status de venda
- Descrição
- Avatar do criador
- Identificação da experiência vinculada
- Universe ID e Place ID
- Verificação de experiência pública
- Faixa etária e nível de maturidade
- Descritores de conteúdo quando disponíveis
- Histórico de pesquisas durante a sessão
- Importação de IDs por TXT
- Exportação de resultados em CSV
- Sistema automático de atualizações
- Verificação de integridade das atualizações por SHA-256

## 🔄 Atualizações

O aplicativo possui sistema próprio de atualização.

Quando uma nova versão estiver disponível, o programa poderá avisar automaticamente e realizar o download da atualização oficial.

As atualizações são verificadas antes da instalação.

## 🔎 Sobre os dados

O Olho do Prime Void consulta somente informações disponíveis publicamente.

Algumas informações podem não ser encontradas caso a experiência esteja privada, removida, arquivada ou não esteja acessível através das interfaces públicas utilizadas pelo aplicativo.
